# Contributing to SentinelX SOC Platform

Thank you for considering contributing to SentinelX!

## Development Guidelines
1. **Fork & Branch**: Create a descriptive feature branch (`feature/add-sigma-parser`, `fix/threat-intel-cache`).
2. **Code Standards**:
   - Backend: Python PEP 8 compliance, Black, and Flake8.
   - Frontend: ESLint, TypeScript strict mode, Tailwind CSS styling conventions.
3. **Commit Messages**: Follow standard conventional commits (`feat: add MITRE attack chain visualizer`, `fix: correct f-string format`).
4. **Pull Requests**: Ensure all automated GitHub Actions CI tests pass before requesting review.
